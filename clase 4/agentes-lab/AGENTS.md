# Instrucciones para agentes

- Lee la spec indicada antes de editar.
- Limita los cambios a los archivos que la spec o el prompt autoricen.
- No agregues dependencias: este laboratorio usa solo Node.js nativo.
- Ejecuta primero las pruebas específicas del ejercicio y luego `npm test`.
- No ocultes fallos ni cambies una prueba para hacer pasar una implementación
  que contradiga la spec.
- Al terminar, informa archivos modificados, comandos ejecutados y cualquier
  criterio de aceptación que no se cumpla.
